Map pictures for Map Config
===========================

Normally you upload these from the map's settings page (drag and drop) and Echelon stores them here as
<mapname>.webp (or .jpg when the server has no WebP support).

You can also copy files in by hand. Name the file after the map, lower case, and use one of
.webp .jpg .jpeg .png .gif - for example:

    ut4_turnpike.jpg

16:9 pictures (for example 800 x 450) look best. Anything else is cropped to 16:9 in the tiles.
This folder must be writable by the web server user for uploads to work.
